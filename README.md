# Beauty User Behavior Analysis
A data analysis project focused on Tmall beauty product user behavior, covering data processing, multi-dimensional analysis, 和 visualization. It aims to explore user behavior patterns, regional distribution characteristics, 和 product preferences, providing data support for store operation optimization.


## File Structure
```
Beauty User Behavior Analysis/
├─ customer_beauty_images/       # Screenshots of analysis results (traffic trends, conversion funnels, etc.)
├─ database/                     # Raw data (customer_beauty_data.csv) and processed data (Excel)
├─ province_value_map.html       # Interactive map of provincial purchase user distribution
├─ customer_beauty_select.sql    # SQL scripts for data query and calculation
├─ 美妆产品用户行为分析报告.md    # Detailed Chinese analysis report (logic, conclusions, suggestions)
└─ README.md                     # Project overview (this file)
```
